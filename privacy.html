Privacy Policy

Last updated: 14 June 2026

This Privacy Policy explains how the Papi Nerd publishing tool (“the Tool”, “we”, “us”) handles information. The Tool is an in-house utility used by the owner of the Papi Nerd content channel to publish the channel's own videos to the channel's own social accounts, including TikTok through the TikTok Content Posting API. The Tool is not a public product and is not offered to third-party users.

1. Who this applies to

The only person who authorizes and operates the Tool is the Papi Nerd channel owner, using their own TikTok account. The Tool does not have other users and does not act on behalf of anyone else.

2. Information we access

  • TikTok OAuth tokens — When the channel owner authorizes the Tool, TikTok issues an access token and a refresh token for the owner's own account. These are used solely to call the Content Posting API to upload the channel's videos.
  • Basic account info — Open id and display name of the authorized account (user.info.basic), used only to confirm the Tool is connected to the correct account.
  • The video files the owner chooses to publish, which are the channel's own original content.

3. Information we do NOT collect

We do not collect, request, store or process any data belonging to other TikTok users. We do not access followers, messages, analytics, or any personal data of viewers. We do no advertising profiling and run no third-party trackers in the Tool.

4. Where data is stored

TikTok tokens are stored locally, on the channel owner's own computer, in a protected folder. They are never transmitted to us or to any third party other than TikTok's official API endpoints. There is no central server and no shared database.

5. How data is used

Tokens are used exclusively to authenticate calls to the TikTok Content Posting API (video.upload and video.publish) in order to upload and publish the channel's own videos. They are not used for any other purpose.

6. Data sharing

We do not sell, rent or share any data. The only data transmission that occurs is between the Tool, running on the owner's computer, and TikTok's official API servers.

7. Data retention and deletion

Tokens remain on the owner's computer until the owner deletes them or revokes the Tool's access from their TikTok account settings. Revoking access immediately invalidates the tokens. The owner can delete the locally stored token files at any time.

8. Third-party services

The Tool interacts with the TikTok API, which is governed by TikTok's own Privacy Policy. Use of the TikTok API is also subject to TikTok's Developer Terms.

9. Children's privacy

The Tool is operated only by the adult channel owner and is not directed to children.

10. Changes to this policy

We may update this Privacy Policy. The “Last updated” date above reflects the latest revision.

11. Contact

For any question about this policy, contact cinquequarti@gmail.com.
